# M1racle PDF Split v1.2.2

VersionName **1.2.2** / versionCode **10**. 本次属于 v1.2.1 之后的界面可读性修复，不更改 PDF 分割引擎的数据处理算法。

## 修复与改进

- UI 主题跟随 Android 系统的浅色与深色设置，不再强制近黑色主题。
- 浅色与深色均采用统一的语义色角色，文字与按钮的关键对比度通过 4.5:1 自动化检测。
- 同步调整 Android 原生启动背景、状态栏与导航栏明暗，减少暗色闪烁和图标难以辨认。
- 顶部标题由 138dp 收缩为 76dp，精简空状态说明、卡片装饰和固定底栏。
- 将并发调节保留在高级设置中，不再占用底栏主操作空间；仅在按目录模式显示目录操作。
- 不再默认填入 `1-N` 页码，避免导入教材后自动准备一个等同于全书复制的输出。
- 界面正文小于 12sp 的字号上调，按钮触控尺寸保持 44dp 或以上。

## 已完成验证

- 本次 UI PR #6（<https://github.com/ldohgfsdu/m1racle-pdf-split/pull/6>）的 Android 14 模拟器浅色、深色及 130% 字体三种截图均完成，界面文字与主按钮可见，未发现空状态中的溢出或重叠。
- Android Debug 编译、JVM 单测、lint、六个有限 TLA+/TLC 模型与故障注入反例、pstack 状态图、发布路径检查均由 GitHub Actions 执行并通过。
- 原有 PDF 拆分算法和 P1 修复内容保持不变。

## 验收边界

- 这一轮截图测试只覆盖尚未选择 PDF 的空状态，没有覆盖导入教材后的各类拆分方式。
- Android 16 真机、988 MB / 420 页医学教材全流程、不同 SAF 提供方的异常情况和 130% 字体下完整工作流仍待专项验收。
- 不宣称仅凭 CI 或模拟器截图已通过完整真机验收。
