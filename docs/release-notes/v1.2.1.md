# M1racle PDF Split v1.2.1

Android 12+，应用包名：\`com.m1racle.reader.pdf\`。versionCode **9**，versionName **1.2.1**。本版修复章节拆分正确性、文件会话污染、页码输入和失败重试，保留 v1.2.0 的 AUTO 解析保护策略。

## 主要修复

- P1-01：切换 PDF 时立即清理旧目录、勾选、预览和结果；异步操作基于 \`sourceGeneration\` 绑定新文件，不能使用旧书目录拆新书。
- P1-02：章节截止页按实际章节边界计算，不再吞入未勾选的章节；整本逐章拆时父章节标题页归第一个子章节，书签前置页单独保存。针对有序书签目录检查页覆盖与不重叠。
- P1-03：指定页码支持 \`1-5,8,12-20\`、\`3-\`、\`-5\` 及中文分隔符。输入错误显示行号并阻止执行；不破坏两列中文教材名称配对。
- P1-04：编辑规则、输出目录或校验设置后使旧结果失效；拆分完成后不能不改参数直接再写同名副本。
- P1-05：单段写入/校验失败时保留已完成段，界面显示已完成文件并提供“重试失败的 N 个”；取消时仍尝试清理本次输出，清理失败明确报错。
- P2-08：结果预览改为完整页面适配，不再截掉章节标题。
- 其他：SAF 输出目录不可读取时阻止写入；回读实际保存的文件名；缓存源 PDF 在复制失败或取消后删除未完成副本。

## 验证

开发分支 GitHub Actions <https://github.com/ldohgfsdu/m1racle-pdf-split/actions/runs/42723766947> 已通过 JVM 单测、Android Debug 构建、Lint、六个有限 TLA+/TLC 设计模型及其故障注入反例、pstack 用户流程状态图生成，以及发布路径安全检查。

这些是 CI 与模型级证据；模型通过不能替代 Kotlin 实际行为测试。会话与章节修复还采用 Grok 先前 Android 14 模拟器的 PDF 产物级复现和修复记录。失败段重试新增 JVM 策略测试，但**尚未在真机 SAF 存储满、权限丢失场景注入故障**。

## 尚未验证

- 未在此次版本的 **Android 16 真机** 上复测。
- 未对 **988 MB / 420 页** 的真实教材重新完整验收；v1.2.0 的历史速度结果不可直接等同于 v1.2.1。
- 加密 PDF 不支持；无文字层、无书签的扫描件仍需手动输入页码，未新增 OCR。
- 部分成功／失败的存储提供方差异、进程强杀恢复及 TalkBack 尚待设备专项验证。

## 安装与安全

仅将 **Release 正式签名 APK** 作为正式升级包。构建必须与 v1.2.0 使用同一签名证书，且 versionCode 必须大于 8。GitHub 发布流水线先创建草稿，再回读 APK 和 SHA-256 附件，验证签名与哈希后才公开。若任何验证失败，则不会公开新 Release。

SHA-256 以同名 \`.sha256\` 发布附件和 GitHub 远端回读结果为准；不预先编造固定哈希值。
